# Literature Notes

## Boundary note

This project is J-space-inspired, not a full Anthropic J-space replication. Any write-up should preserve that distinction.

## Working contrast

Prior related work commonly examines visible reasoning traces, especially chain-of-thought tokens. This project asks whether hidden representations under answer-only prompting contain reasoning-like structure even when no visible reasoning is requested or analyzed.

## Notes to collect

For each paper, post, or implementation note, record:

- citation
- method summary
- whether it studies visible tokens, hidden states, or both
- model family
- task family
- relevance to answer-only / no-CoT probing
- limitations

## Open reading list

- Mechanistic interpretability work on hidden-state probes.
- Studies of chain-of-thought faithfulness and unfaithfulness.
- Work on latent reasoning, representation geometry, and activation steering.
- Original J-space-related materials, with care not to overstate replication.
